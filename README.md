Developed an AI-Powered expense tracker. I named it Spendwise-AI. You can use it: https://spend-wise-ai-sable.vercel.app/
- Made using MERN stack.
- Implemented authentication using JWT.
- Implemented dynamic expense management: Date-based CRUD, 500ms-debounced search, and pagination.
- Users can set and update budget for every month and warning shown if they exceed the budget.
- Built interactive yearly-expense visualization using Reacharts bar graph. Printable PDF of expenses.
- Integrated OpenAI API to generate spending insights and saving tips based on user expense data.
